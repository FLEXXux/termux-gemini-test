# termux-gemini-test

Aesthetic glowing dark-theme web landing page crafted inside Termux using Gemini CLI.

## ✨ Features

- **Dark Neon Aesthetic:** Deep obsidian tones layered with multi-colored ambient aura glow spheres (cyan, purple, and neon pink).
- **Interactive Particle Constellation:** 60 FPS interactive HTML5 canvas particle network with fluid physics and cursor/touch reactivity.
- **Glassmorphism UI:** Modern frosted-glass containers with subtle luminous borders, dynamic refractions, and responsive layout.
- **Pure Web Standards:** Zero heavy dependencies — pure semantic HTML5, modern CSS3, and vanilla JavaScript.

## 🚀 Quick Start

Open `index.html` in any modern web browser or serve it locally:

```bash
# Using python built-in server
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
